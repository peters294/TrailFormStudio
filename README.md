# TrailForm Studio privacy policy

This repository contains the English privacy policy for TrailForm Studio (`com.kpbteam.trailform_studio`).

- `privacy-policy.md`: editable policy text.
- `index.html`: standalone HTML version for GitHub Pages.

To publish the HTML page, open repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. Use the public URL reported by GitHub Pages in Google Play Console.

Privacy contact: bus.piotrek@gmail.com. Update both policy copies together when the policy changes.
